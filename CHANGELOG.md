# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-25

### Added
- Order on WhatsApp button on product pages with live variation, quantity and price.
- Optional buttons on shop pages, cart button (classic cart and Cart block) and floating chat button.
- WhatsApp-only mode that hides Add to cart buttons.
- Editable message templates, button texts and color; Bangladeshi number conversion.
- Shortcode `[order_on_whatsapp]`.
- Hooks: `oow_show_product_button`, `oow_product_message`, `oow_cart_message`, `oow_option_{key}`.
